## 🚀 About Me

I'm a **full-stack software engineer** from **Zimbabwe 🇿🇼** who designs, builds and ships production systems end to end — from the Django API and the database, to the React web app, the React Native mobile app, and the ESP32 sensor in the field.

- 🏢 **Founder & lead engineer at [Dubzig Investments](https://dubzig.co.zw)** — building SaaS products and delivering client platforms for schools, churches, farms, retailers and events.
- 🧠 **Research:** LLM systems for **Shona language learning & cultural heritage preservation**, and **AI-assisted self-regulated learning** for programming education.
- 🌍 **Building for African realities:** offline-first apps, low-bandwidth UX, EcoCash / OneMoney payments, and shared-hosting-friendly deployments.
- ⚡ **30+ projects** built and deployed across **EdTech, AgriTech, FinTech, IoT, logistics and cultural tech**.
- 🤝 **Open to** remote roles, freelance contracts, technical partnerships and startup collaborations.

## 🧭 How I Build

- **Offline-first when the network can't be trusted.** Sales, stock and hymnals keep working without a signal.
- **AI that stays grounded.** Retrieval, approved answers, and verification before anything reaches a user.
- **Deployments that fit the client's hosting.** Pinned dependencies, pure-Python wheels, and Passenger on cPanel when that's what the client has.
- **Honest documentation.** Architecture notes, API references and status reports that separate what's verified from what's only written.
